# ARENA-Agentic-Reasoning-Evidence-Network-for-Athletics
ARENA is an Olympic knowledge system that combines Vector RAG, GraphRAG, and Agentic GraphRAG. It uses FAISS for unstructured retrieval and TigerGraph for structured data like athletes, events, and medals. An agentic layer dynamically plans searches, evaluates evidence, and replans to provide answers with an inspectable reasoning trace.
